# 这些致命毒物每家都有，孩子误服家长千万别作这个动作！

> 更新时间：2026-09-16 (UTC+8)

如果孩子误食了有毒的化学产品怎么办？

“大量喂水，清洗口腔，稀释毒素！”

这是不是屏幕前的您首先想到的急救方法？

大多数的家长第一反应都是如此

可最近到省妇幼救治的两个孩子

却因为家长的这个习惯性动作而加重了病情

这是怎么回事呢？

**两幼童误服“管道疏通剂”**

**家长同一个习惯性动作害了伢**

家住洪山区的小橙子（化名）趁奶奶不注意，溜到卫生间拿起“管道疏通剂”喝了一口，感到难受的他哭着跑到奶奶身边。奶奶发现孩子口里流涎不止，卫生间里“管道疏通剂”的瓶子已被拧开，洒落一地的疏通剂，立刻用清水冲洗了橙子的口腔，并要儿子媳妇赶回家来。

橙子父母到家后，立刻带着孩子和“管道疏通剂”的瓶子前往省妇幼急诊科。此时橙子的嘴唇和口腔已被灼伤，明显肿胀，立马被转至儿童重症医学科。橙子妈妈请求医生给孩子洗胃，接诊的夏治副主任医师询问患儿病情并查看那瓶“管道疏通剂”的说明后，确认其为“强碱性”化学物品，立刻否定了洗胃的请求，并给橙子大量饮用纯牛奶，同时给予保护胃肠道、抗过敏和对症支持治疗。经过两天及时有效治疗，橙子的病情总算转危为安。

无独有偶，数天前3岁男孩皓皓也误吃了一口“管道疏通粉末”，并出现了反复呕吐和口唇发绀的情况。皓皓爸爸也是给他用清水冲洗口腔后才送医。儿童重症医学科秦晨光医生接诊时，皓皓不仅出现了口唇明显肿胀，口腔内还有大范围的灼伤，以及严重的消化道出血。经过8天的有效治疗，病情才终于平稳下来。

**清水清洁适得其反**

**口服牛奶缓冲保护 **

为什么医生拒绝了家长洗胃的要求，反而给孩子饮用大量纯牛奶？

为什么清水清洁的习惯性动作，反而加重的孩子的病情呢？

儿童重症医学科许慧主任提醒家长：

强酸或者强碱遇到水会释放更多的热量，增强腐蚀效果，会增加口腔、消化道灼伤，增加消化道穿孔的可能性。

孩子误服清洁剂等化学品，口腔和消化道已被强碱灼伤，而清洁口腔的习惯性动作，会加重强碱的腐蚀效果，导致口腔和嘴唇肿胀明显，加重对消化道的灼伤，但口服纯牛奶却可以达到缓冲化学物品对胃肠道灼伤的作用。

**危险就在身边！**

**这些致命毒物每家都有**

一说起“腐蚀性化学品”，很多人第一反应往往是很可怕，然后觉得似乎离我们的日常生活很远，心想说是不是工业上的，或家里人有特殊职业的，才能接触到这些东西。

其实，“腐蚀性”也有强有弱，日常生活中能接触到化学品可是几乎每家都有的哦！

**#元凶二： 火碱**

●河南一名1岁5个月的宝宝误食了爸爸用于清洗油烟机的火碱，奶奶慌乱之中接了一杯水让孩子漱口，导致情况更加糟糕，孩子呼吸道和食道大面积烧伤，肺部水肿，出现生命危险。

●山东1岁半男童，误将火碱当白糖吃下，正在屋内的奶奶听到哭声后跑出去一看，小孙子整个口腔已发黑，慌乱中的奶奶赶紧用水给孩子清洗，结果火碱流到肚子上、腿上...加重了伤情，消化道和声带都受到了极大损伤。

**#元凶三：电池**

重庆3岁多女童到医院就诊，医生从她的食道内取出一枚和1角硬币大小相近的纽扣电池，电池中漏出的强碱性液体致使她的食道被烧伤，全食道僵硬，出现食道疤痕性狭窄，几乎丧失功能。

据报道，2013年至2014年，全美各地毒物控制中心接获的报案电话增加17%，其中有逾2.2万名孩童吞食或不当接触洗衣凝珠。这些孩童大多在3岁以下，已有2人不幸丧生。

除了以上这些家中常见的“罪魁祸首”

还有食品中的**干燥剂**、衣柜里的**樟脑丸**

**84消毒剂、75%酒精**等等

都是可能伤害到孩子的「危险因素」

**发生误食怎么办？**

**不同物品处理方法不同**

这么多痛心的事件

在时时刻刻提醒家长

给孩子创造一个安全的生活环境十分重要

同时也要加强对孩子的安全教育

做好儿童安全防范工作

**预防孩子误食，这些事情要做好**

**1、加强“入口”东西要询问的教育**

从宝宝小的时候，家长就应该多教育ta，无论想吃什么东西，都要先询问爸爸妈妈的意见才能吃。

当家长不停地强调，宝宝也会渐渐形成了这种“入口询问”的意识，便不会随意将东西放入口中。

**2、放在孩子接触不到的地方**

家里的药物、消毒剂、工具箱等东西，应该放在孩子无法接触到的地方，特别是药物，最好能用带锁的药箱储存。

每次用完药之后，拧紧瓶盖，放回药箱，并上锁。

**3、****过期、无用的物品要及时****扔掉**

宝妈们平时也要养成习惯，定期检查家里的药物有无过期的，及时妥善清理。

每次打开物品时，都要看看里面有无含有干燥剂，随后扔进垃圾桶，并用其他垃圾覆盖，并注意不要和带有水分的垃圾一起丢。

**4、做好用品的检查工作**

如果平时孩子玩的玩具有零小物件，也要多多检查，如果发现有零件松动的风险，就要及时的处理。

平时也不要给孩子买磁力珠、玻璃球、水宝宝这种危险玩具。

**5、不要把药物说成糖丸**

不要为了哄骗孩子吃药，就习惯性告诉孩子，药是糖丸。

而是应该从小就给孩子树立正确的观念，这是药物，作用是什么，平时药是绝对不能乱吃的。

**6、不要随意更换用品包装**

不要随意用饮料空瓶或者卡通瓶罐去储存物品，特别是消毒剂、药品。如果有分装的情况，也应该做好标示，放在接触不到位置，防止误服。

对小孩子来说，他们基本没有能力去鉴别这个东西能不能吃，所以做父母的更要严格把关。千万别让自己的一时疏忽，造成一辈子的遗憾！

**再次提醒**

千万不要将

消毒剂、清洁剂等物品

放在饮料瓶中

也不要放在孩子能触及到的地方！
